KeyChat 隐私政策

版本：1.0　｜　更新日期：2026 年 7 月 26 日　｜　生效日期：2026 年 7 月 26 日

概要： KeyChat 是一款本地优先的 BYOK（用户自备 API Key）AI 对话客户端。KeyChat 不设自有账号体系，不运营用于中转聊天内容的服务器，也不集成广告、行为分析或崩溃上报服务。API Key、提供商配置、聊天记录、智能体配置和附件主要保存在用户设备本地。只有当用户主动测试连接或发起对话时，相关请求数据才会直接发送至用户选择或配置的第三方 AI 服务。

二、KeyChat 如何处理数据

数据类型 用途与处理方式 保存位置与期限
API Key 用于向用户选定的 AI 服务进行身份验证。发起连接测试或对话请求时，API Key 会作为认证信息直接发送给相应服务。 保存在设备的系统安全存储中，直至用户在提供商配置中删除、清除应用数据或卸载应用。
AI 提供商配置 包括提供商名称、HTTPS Base URL、模型 ID、协议类型、启用状态和模型附件能力，用于建立和管理连接。 保存在设备本地数据库中，直至用户删除配置、清除应用数据或卸载应用。
聊天与智能体数据 包括会话标题、消息内容、模型信息、系统提示词、智能体名称和描述，用于展示本地历史记录以及构造用户主动发起的 AI 请求。 保存在设备本地数据库中，直至用户删除对应内容、清除应用数据或卸载应用。
用户主动选择的附件 包括文件名称、类型、大小和文件内容。用于本地聊天记录；当用户使用支持附件的模型发送消息时，附件内容会直接发送给用户选择的 AI 服务。 复制并保存在应用私有目录。当前版本删除对话会删除相应的数据库记录，但已复制的附件文件可能继续保留，直至用户清除应用数据或卸载应用。
应用设置 例如语言偏好，用于记住用户选择并提供相应界面。 保存在设备本地，直至用户清除应用数据或卸载应用。

KeyChat 不要求注册账号，不主动收集手机号码、通讯录、精确位置、广告标识符或设备唯一标识符。用户可能在对话或附件中自行输入个人信息；发送前请确认确有必要，并了解所选 AI 服务的隐私规则。

三、向第三方 AI 服务发送数据

KeyChat 本身不提供大语言模型。用户只有在主动测试连接、获取模型列表或发送消息时，应用才会按照用户选择的 HTTPS Base URL 直接访问相应服务。可能发送的数据包括：

  • 用于认证的 API Key；
  • 所选模型 ID、提供商所需的请求参数；
  • 当前请求所需的聊天消息、系统提示词和会话上下文；
  • 用户主动添加且由所选模型接收的图片或文件附件。

内置入口包括 OpenAI、DeepSeek 和 OpenRouter。自定义提供商预设可能包括 Kimi、Xiaomi MiMo、智谱 GLM、Google Gemini 和阿里云百炼 Qwen；用户也可以自行配置兼容 OpenAI Chat Completions 的 HTTPS 服务或网关。实际接收方、服务器所在地、保存期限和后续处理规则取决于用户最终选择的服务。

在使用第三方 AI 服务前，用户应阅读并同意该服务的服务条款和隐私政策。若用户选择位于境外或在境外处理数据的服务，相关信息可能被跨境传输和处理。请不要发送无权披露的信息、国家秘密、商业秘密或非必要的敏感个人信息。

四、系统权限说明

权限或系统能力 用途
网络访问 根据用户配置访问 AI 服务、测试连接、获取模型列表并完成聊天请求。KeyChat 只允许应用内配置使用 HTTPS 地址。
通知 在 Android 系统要求许可的版本上显示生成任务的状态或控制通知。用户可以在系统设置中关闭通知权限。
前台服务与数据同步 在用户主动发起生成任务后维持请求，并通过系统可见的前台服务通知展示运行状态。
系统文件选择器 仅在用户主动选择图片或文件时访问所选内容。KeyChat 不申请读取全部存储空间的权限。

五、数据共享、转让与公开披露

除用户主动调用所选 AI 服务、主动通过系统分享功能导出内容，或法律法规另有要求外，开发者不会将本地数据出售、出租或提供给其他主体，也不会公开披露用户数据。

当用户使用“分享”或“导出”功能时，数据将交由用户自行选择的其他应用处理；后续处理受该接收应用的隐私政策约束。

六、数据安全

  • API Key 使用设备系统提供的安全存储保存；
  • 提供商连接仅允许使用 HTTPS；
  • Android 端禁止系统云备份 KeyChat 的应用数据；
  • 应用不在开发者自有服务器中转聊天请求；
  • 应用不集成广告、用户行为分析或崩溃上报服务。

互联网传输和终端设备不存在绝对安全。用户应妥善保护设备和 API Key，避免在截图、录屏、聊天内容或问题反馈中暴露完整密钥，并建议为第三方服务设置合理的额度限制。

七、用户如何管理和删除数据

  • 在“提供商”配置中查看、修改或删除提供商配置和 API Key；
  • 在会话列表中删除聊天记录；
  • 在智能体页面修改或删除智能体配置；
  • 通过系统设置清除 KeyChat 的全部应用数据；
  • 卸载 KeyChat，以移除应用在设备上的本地数据。

如需就本政策所述处理活动提出查询、更正、删除、解释或投诉请求，请通过本政策顶部列出的邮箱联系开发者。对于第三方 AI 服务保存的数据，请同时按照该服务提供的渠道直接行使相关权利。

八、未成年人保护

KeyChat 面向具备相应民事行为能力并能够自行管理第三方 API 服务的用户。未满 14 周岁的未成年人应在监护人阅读并同意本政策及相应第三方 AI 服务规则后，在监护人指导下使用。请勿通过 KeyChat 输入或发送非必要的未成年人敏感个人信息。

九、政策更新

如 KeyChat 的功能、数据处理方式、系统权限或第三方服务发生变化，本政策将相应更新，并修改页面顶部的更新日期。涉及处理目的、方式或个人信息种类的重大变化时，将依法另行提示或征得同意。

十、关于本网页

本隐私政策网页不使用 Cookie，不加载广告、统计分析、追踪脚本或第三方字体，也不设置收集个人信息的在线表单。
